# 分块备份格式 v1

当前应用版本：0.5.0（versionCode 8）；归档魔数与容器格式仍为 v1，内部 Snapshot 为 protocol 2/schema 4。格式最初引入于0.2.1。扩展名 .x3backup，MIME application/octet-stream。导出只在手机提供；恢复仍由手机作为日程定义权威，最初不改变 BLE protocol 2/schema 3 或 SQLite schema 3；0.3.0 的 BLE 和数据库后续变化见 PROTOCOL.md，备份格式仍为 v1。

## 容量与内容

整个文件最大 32 MiB（含魔数、长度字段、结束标记与摘要），最多 1000 个计划、50000 个实例、50000 个事件、4096 个分块。每块为最多 2 MiB 的严格 UTF-8 Snapshot JSON。单个计划及其历史分段不可跨块；若单项超出分块大小，导出失败，不截断或省略。限制允许长期历史超过同步容量后另行备份，不保证无限容量。

内容与手机 Snapshot 相同：计划/删除标记、历史实例、事件、设置和设置版本。本机建议处理记录、配对选择、权限、提醒已发送标记、inbox/outbox 不在备份内；已接受建议产生的计划修改在备份内。

## 字节布局

1. ASCII 魔数 X3SCHEDULE-BACKUP/1 后接单个 LF（20 字节）。
2. 一个或多个分块：4 字节有符号大端整数 N（1 到 2097152），紧随 N 个 JSON 字节。
3. 4 字节整数零为结束标记。
4. 32 个原始 SHA-256 摘要字节，覆盖从魔数开始至结束标记末尾的所有原始字节。
5. 必须立即 EOF，不允许尾随内容。

首块是必需的空数据头：plans、instances、events 均为空。所有块的 protocol、schema、id、source、deviceId、settings、settingsVersion、revision 必须与首块相同（按 Gson 模型再序列化比较）；source 必须是 phone。所有块均经过既有严格 JSON 结构、深度、UTF-8、字段类型及模型语义校验。聚合后拒绝跨块重复计划/实例/事件 ID。摘要提供损坏和截断检测，不是密码加密、数字签名或来源认证。

当前写入顺序为：空头 → 每计划一块 → 每 64 个实例一块 → 每 64 个事件一块 → 结束标记和摘要。读取器允许任意数据块顺序，但要求一致元数据、合法数据、数量/字节边界及全文件摘要。分块只能用于本地备份，禁止直接作为蓝牙数据发送。

## 文件交互与事务

通过系统文件选择器选择输出位置或输入文件。备份在独立线程及数据库句柄中读一致性快照，先结束读取事务，再逐块写文件。读取先校验整份文件，展示计划、实例和事件数量；确认按钮使用同一份已校验内容，不重新读取可能已变化的外部文件。恢复在后台单一数据库事务内完成，计划与事件冲突使本次合并整体回滚。成功后重建未来实例、标记待同步并安排提醒；提醒安排失败与数据恢复失败分别提示。

流式传输只缓存一个原始分块，不分配整份文件的字节数组或全文字符串。但目前导出快照及解码后的完整模型列表仍驻内存，并非逐行数据库游标或无限流式恢复；32 MiB/数量限额是边界，真实手机峰值内存和耗时待验证。用户应保持应用打开；离开页面/旋转后不向已销毁界面写入，已开始的工作仍可能完成，预览丢失需重新选择。没有跨进程断点续写。进程被结束或存储提供方失败可能留下不完整文件，必须重新导出；无完整结束标记、摘要或 EOF 校验的文件不能恢复。不会自动删除或覆盖其他备份文件。

## 兼容与验证

不含新魔数的文件按既有 JSON 备份读取：最多 2 MiB，要求严格 UTF-8/JSON，支持 phone protocol 1/schema 2、protocol 2/schema 3 验证后迁移，以及当前 protocol 2/schema 4，保留原数量限制。当前新备份要求0.5.0或同时支持容器v1与schema4的版本读取；旧备份仍可迁移。0.3.0 已另行接入有持久化进度的 BLE 分批同步，详见 PROTOCOL.md。

主机测试覆盖超过 2 MiB 及超过 12000 实例的完整往返、源快照不变、空备份、旧 JSON、截断、摘要错误、尾随内容、来源/修订混块、跨块重复、缺失或非空头、恶意长度、32 MiB 总量、记录上限、分块洪泛及流所有权。Android 合成数据库测试增加恢复幂等性和事件冲突后的计划/待同步修订回滚；测试包构建不代表已执行这些设备测试。

旧 JSON 或旧分块备份必须先满足原版本语义：不能带全天、多日、月日/按年重复或扩展单次覆盖的非默认值。所有原始块须具有一致 protocol/schema，再执行迁移；摘要仍验证原始字节。实时蓝牙归档不启用旧备份迁移路径。
