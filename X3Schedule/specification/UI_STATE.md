# 页面与草稿恢复

适用版本：0.5.0。此能力恢复系统保留的 Android Activity 状态，不创建已保存日程，不改变同步或备份格式。

## 恢复内容

- 保存当前首页栏目、页面、滚动位置、表单原始文字及下拉选项。文字不提前去空格或验证，未写完的日期、数字也保留。
- 编辑页保留源计划及其稳定 ID；预览保留尚未提交的计划列表及导入标记。恢复仍需用户预览、确认才能保存。
- 日程详情按实例 ID 重新读取正式记录；计划详情重新读取当前计划。对象不再存在时退回首页并提示。
- 已请求的报告按恢复的筛选重新计算，结果产生后再恢复滚动位置。不会将过时统计结果作为新数据展示。
- 手机常规横竖屏继续使用原有 View 重新布局；字体变化等 Activity 重建使用本规范的保存状态。

## 不能自动重放的操作

恢复代码不点击按钮，不自动保存、打卡、删除、接受优化建议、写文件、选蓝牙设备或申请权限。设备选择页退回连接页；备份读写或无法重建的临时确认页退回首页并提示重新发起。

外部文件选择器返回仍遵守原回调：需要内存中导出内容或日历计划的操作，重建后可能提示已过期，应重新发起。系统已返回的用户选择不等同于恢复代码重放文件操作。

## 容量与生命周期

`ScreenSession` 使用 schema 1 JSON，经 `onSaveInstanceState` 放入系统 Bundle。JSON 上限 24000 个 UTF-16 code units（字符串负载约 48 KiB），给 Android 其他状态留出空间。超限不截断计划或表单，而是只保留首页栏目和明确的失效提示；用户应重新打开较大的导入/预览。未保存内容不会写入正式数据库。

损坏状态、未知 schema、非法栏目或负滚动位置回退到首页；不尝试修复或提交不完整记录。此状态不作为跨版本数据交换格式。

依赖系统已调用状态保存且保留当前任务；不承诺强行停止、清理任务、崩溃、重启设备或卸载之后仍保留草稿。没有常驻磁盘草稿自动保存、后台编辑同步或永久草稿箱。

## 验证

主机 `ScreenSessionTest` 验证未完成输入、待办身份、预览、报告筛选、超大表单/预览以及损坏状态的回退。

两端 Android 测试包可使用 `uiState=true` instrumentation 参数运行独立原生控件检查：标签定位、不同排列和嵌套布局、空输入、非法选项、不得重放提交。此模式不启动正式 Activity，不打开数据库，也不申请设备权限。编译成功不代表该设备测试已运行。

完整实机验收仍须在获得设备连接确认后完成：系统字体变化触发重建；带无效输入的三类编辑；报告自定义筛选和结果滚动；后台任务保留条件下进程终止后恢复；导入/导出中断；确认没有新增计划或重复执行记录。

## 日历与编辑器

保存所选日期、月/周/日视图模式及纵向滚动位置；异步日历加载完成后恢复纵向位置。周/日时间轴横向位置按dp保留，异步布局后恢复；切换日期或视图时回到起点。定时刷新和系统保留任务的Activity重建保留位置，实际系统生命周期仍需设备验收。

编辑器保存所选影响范围、已确认的日期/重复/提醒设置和草稿；子弹窗未确认内容在重建后取消，不产生保存操作。未来投影详情保留有界实例快照并核对计划版本；失效时返回安全入口。已保存历史仍按正式记录读取。新路径尚待设备生命周期验收。

预览和保存均使用独立后台任务。预览读取一致快照后重算；已确认保存以独立数据库句柄执行原有原子事务，按钮立即禁用以防连续点击。离开页面或Activity销毁只丢弃显示回调，不能撤销用户已经确认的保存；返回后应在日历核对。进程在提交前被结束由SQLite回滚，提交后数据保留。恢复页面不会自动发起保存。保存成功而提醒重排失败会明确区分，不误报整个保存失败。
