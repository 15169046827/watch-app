# 日程隐私说明

版本：0.7.0个人 GitHub 预览版；更新日期：2026-10-18；发布者：Ym_Li。

日程是本机日历、提醒和执行记录工具。无需账户，不申请 Internet 权限，不接入服务器、广告、统计或云端模型。自然语言录入和完成情况分析在本机完成。

## 数据与权限

应用私有目录保存日程定义、日程实例、完成记录、提醒设置、设备选择、同步副本和本机建议处理历史。你选择已配对设备后，应用通过蓝牙将相应数据同步到该设备。拒绝蓝牙权限时可继续使用本机功能；手机通知和准时提醒权限影响手机提醒是否及时出现。手表本地日程通知已停用，通知权限仅用于可选后台连接状态。后台连接另行开启，系统省电、强行停止和设备不在范围内可能延迟同步与提醒。

新等级任务还保存你填写的完成标准、成果与行动反馈、补救承诺、冲突确认、请假及让位事实，以及该任务当时采用的规则、时区和任务日边界。更正通过新增引用记录保留原始事实，已确认完全没做的失约不会被后来提高成果抹去；这些记录仍在本机处理，并包含在你主动进行的备份和双端同步中。二分模式的未完成不自动视为没有行动。

手机备份包含日程、实例、完成记录及可迁移设置，未加密；仅写入你在系统选择器中选择的位置。导出文件不包含系统权限、蓝牙密钥或本应用后台关联授权。恢复前显示内容数量，由你确认合并；恢复不会替你重新授予权限或选择设备。

## 本机数据管理

手机设置及手表主页均提供“隐私与本机数据”。每项清除均说明范围并二次确认：

| 类别 | 清除范围 | 保留内容与注意事项 |
| --- | --- | --- |
| 日程与记录 | 本机日程、实例、完成记录、建议历史、提醒去重信息和同步副本 | 保留提醒设置、设备选择和系统权限；同步暂停，需要在连接页明确恢复。另一台设备保留的数据可能重新传入。 |
| 缓存 | 本应用私有缓存目录、未完成同步的输入与输出副本 | 保留日程、记录、设置、设备选择及已完成批次收据；同步副本按新批次重新生成。 |
| 设备连接配置 | 本应用设备选择和后台关联，停止本机自动同步 | 保留日程、记录、系统蓝牙配对和权限；重新连接需选择设备，后台关联需重新授权。 |
| 全部本机数据 | 系统清除本应用私有数据、缓存及设置，同时重置本应用权限、通知和文件访问授权 | 应用关闭；下次打开重新设置。不会卸载应用、删除另一台设备数据或已导出的外部文件。 |

日程没有账户口令或云端凭据。清除前请先完成双端同步，并在手机导出、校验备份；手表独有的未同步记录会在清除后丢失。清除本机不是从两台设备同时删除数据的指令。

分类清除会等待已提交的保存、备份及同步操作结束。未完成的同步副本可以重新传输；清除日程与记录不会生成删除另一台设备数据的同步指令。系统“全部本机数据”操作由 Android 执行并终止应用。

卸载或清除应用无法删除你此前主动导出的文件，请自行管理这些文件及其副本。系统蓝牙配对可在系统设置管理；本应用不会删除其他应用的数据。

## 报告问题

通过安装包对应的 GitHub 发布页反馈问题。请勿上传包含私人日程、完成记录、设备地址或权限截图的原始文件；优先提供版本、可复现步骤和不含个人信息的合成示例。
