# 日程视觉规范

版本：0.5.0（视觉资源沿用 0.4.0）。沿用仓库 `design/icon-system/SPEC.md` 的日常工具家族语言，项目内定义日程的新增配色。系列公共规范不由本项目直接修改。

## 产品图标

母版 `app-icon.svg`：灰莓红 `#B56F8C`，暖白 `#F7F3EA` 与深炭 `#2F3437` 前景；宽体日历、双装订环、两条日程与完成标记。手机和手表使用同一图形，不使用日期数字、时钟或同步箭头。

`python tools/generate_icons.py` 从母版生成共享 Android 资源；`--check` 检查资源一致性。完整纯色背景与透明前景分开，adaptive 前景围绕 `(24,24)` 缩放 `0.72`，此数值是既有 OPPO Watch X3 标定。保留完整正方形 fallback，icon 与 roundIcon 一致。不预制圆形背景、不添加阴影或渐变。

## 界面与层级

| 用途 | 手机 | 手表 |
| --- | --- | --- |
| 背景 | `#F6F8F7` | `#090C12` |
| 卡片 | `#FFFFFF` | `#191F29` |
| 主文字 | `#13251E` | `#F5F7FA` |
| 次要文字 | `#5E6D66` | `#9DAABC` |
| 主操作 | `#8E4F69` | `#D99AB4` |
| 主操作文字 | `#FFFFFF` | `#291820` |
| 浅强调/次级底色 | `#F6E9EF` | `#26303C` |
| 错误文字 | `#A52E46` | `#F38E97` |

次要文字比最初协调建议略加深，以保证浅色背景上的普通文本对比度至少 4.5:1。颜色不单独表达状态，同时保留状态文字。采用系统中文字体，不额外打包字体。

- 手机：日历、日程、报告、设置四栏；日历首页提供月历、选日、周/日时间轴及新建。当前/下一项和待确认保留在日程页。日程页保留管理与自然语言预览，报告页保留本地优化建议，设置页保留提醒、连接、备份与容量。
- 手表：独立首页呈现当前、下一项、待确认/待办、设备入口；仅执行型当前日程提供直接“刚刚完成”，仅提醒型无打卡按钮。复杂编辑只在手机。
- 手机内容居中、最大 640dp，两侧 20dp；手表左右 36dp、顶部 38dp、底部 44dp。长标题自动换行，页面可纵向滚动，保留手表右滑返回。
- 标题手机 26sp/手表 21sp，分组 18sp/16sp，正文 14–16sp，辅助信息 12–13sp。按钮至少 48dp，圆角 16dp，保留按压、焦点和禁用反馈。
- 手机窗口处理系统栏、屏幕切口及键盘边距；API 26 保留深色导航栏，API 27+ 使用浅色导航栏。横屏下内容以实际可用宽度居中。
- 今日汇总按本机日历日计算，跨午夜与夏令时正确；单项时间仍按日程时区显示。执行状态沿用领域规则，提醒不纳入待确认，未定期待办不占当前/下一项。
- 首页汇总使用独立数据库句柄在后台读取一致快照；页面离开后丢弃显示结果。定时刷新作用于日历/手表首页，不重建报告筛选表单。

## 验证与边界

`python tools/check_design.py` 检查两端文本对比度、矢量导出一致性及 Manifest 接入。`tools/render_design.py --font <中文字体> --out <PNG>` 使用 Pillow 生成设计参考图，配色与图标来自实际资源，页面内容为合成示例，不能代替 Android 截图或交互验收。

本版保留包名、权限、签名及图标资源；数据库升级5、内部Snapshot升级4，详见数据与协议规范。新界面不代表提醒/后台可靠性获得额外证明。圆屏实际裁切、启动器缩放、长标题/大字体、横竖屏、键盘和导航手势必须在两端设备另行验收。

页面重建恢复的字段、容量上限及不自动重放的操作见 `../specification/UI_STATE.md`。该能力仍需系统字体变化与任务恢复的真实设备验收。

0.5.0 编辑页采用摘要行与二级弹窗，日期和分钟在同一面板确认。周/日时间轴按本机时区，全天独立显示；具体事件最小可视高度48dp。可读分列至少80dp宽；无法满足时将同一重叠组聚合为可打开的完整列表，长标题与大字体仍需设备验证；不能将静态资源检查视为日历界面验收。
