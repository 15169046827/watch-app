# 日程 0.7.0 · 个人 GitHub 预览版

发布者：Ym_Li。发布轨道：LIMITED PREVIEW。版本：0.7.0 / versionCode 17。

日程是一款本地日历与任务记录工具。手机安排日程和查看报告，手表查看、反馈并同步；无需账户，不申请 Internet 权限。此批次为个人预览版，已通过批准范围内的验收，不代表适配全部 Android 手机或手表。

## 下载与安装

- 手机：`X3Schedule-Phone-0.7.0-release.apk`，Android 8.0/API 26及以上；实测小米13。
- 手表：`X3Schedule-Watch-0.7.0-release.apk`，Android API 26及以上，针对 OPPO Watch X3 的定制 Android 11/API 30圆屏验证；不保证标准 Wear OS 或其他手表兼容。
- 请将对应 APK 安装到对应设备，两端必须一起升级到0.7.0或协议兼容版本。验收版、Debug版和测试包不属于此发布。
- 下载后可按 `SHA256SUMS.txt` 校验文件完整性；APK 使用独立 Release 签名，证书 SHA-256 见 `manifest.json`。

首次启动阅读隐私说明。在系统蓝牙中配对手机和手表，再在两端“连接与权限”中选择对方；手机按提示允许附近设备、通知以及可选后台连接。手机需要允许应用自启动/后台运行，厂商省电策略、强行停止和权限撤销可能延迟提醒或同步。

## 本次功能

- 执行任务可自定义完整、基本、最低行动标准；不填写标准时使用完成/未完成。
- 分开显示实际成果与计划执行得分，日/周任务卡片和月视图按规则着色，待确认单独标记。
- 可选固定补救时段，冲突显式处理，逐项确认受影响安排；手表只反馈及启用无冲突补救，时间表修改在手机完成。
- 任务日默认凌晨4点，可自行设置。区分自行补做、过去三任务日补录及保留原始事实的更正；确认完全未行动前会二次确认，之后不能撤销该次失约。
- SQLite6 / Snapshot schema5 / BLE批次4。旧任务保留原规则，旧备份通过恢复入口迁移。
- 修复数据库迁移注释解析、初次显示的主按钮颜色，以及自动补救邀请保存后详情未刷新的问题。

## 升级与恢复

升级前先完成双端同步，在手机“设置 → 备份与 ICS”导出完整 `.x3backup`，确认备份可预览，再保留一份安全副本。备份未加密，包含私人日程与执行记录；系统权限、蓝牙密钥和后台关联授权不在备份内。

同 Release 签名的0.6.1可保数据覆盖升级到0.7.0，两端一起升级。本次已验证该路径；不要先卸载正式应用。若系统提示签名不兼容，停止安装并先核验原版本来源。共享 Debug 签名不能直接覆盖为 Release，必须在验证备份并明确接受本机数据和权限清除后单独迁移；不要为解决安装失败而直接卸载。

不要将旧 APK 强制降级覆盖新数据库，也不要假设0.7备份可恢复到0.6。需要恢复时优先使用同版0.7.0及已验证备份，导入前核对预览并确认合并；恢复不代替重新授权和选择设备。只有持有升级前旧版兼容备份并接受重新安装导致的本机数据及权限丢失，才考虑退回旧版。未同步的手表记录不会自动出现在手机备份中。
