# Watch App 生产发布验收清单

- 适用标准：WARS 1.1.0、WATCH-APP-UPARS 1.1.0、UPARS 1.0.0
- 适用产品：记账手表端、记账手机端、笔记、听读、听读工坊
- 原则：代码审计通过不等于生产发布通过；所有适用项均有证据后才可放行

## 一、发布批次信息

- [ ] 记录产品、版本号、构建时间、源提交和构建环境
- [ ] 记录产物绝对路径、文件 SHA-256 与预期安装目标
- [ ] 记录本批次的已知限制、升级来源版本、回滚和数据恢复方法
- [ ] 确认构建来自已审核工作树，未夹带缓存、测试凭据、私人页面 ID 或用户内容

## 二、代码与共享门禁

- [ ] 最新逐产品报告为代码审计 `PASS`，无未关闭 P0/P1；P2 已关闭或按标准批准
- [ ] 代码规范、实际执行的单元/独立测试、Android Lint 和适用的前端/Rust 检查通过
- [ ] Debug、AndroidTest 及正式构建路径通过；`NO-SOURCE` 不计作测试证据
- [ ] WARS、WATCH-APP-UPARS、网络安全正向门禁和负向夹具通过
- [ ] 差异、脚本语法、凭据模式和版本状态生成物检查通过

## 三、签名与产物身份

- [ ] 四个 Android 正式产物使用同一把仓库外 Release Key
- [ ] Release 证书 SHA-256 已预登记，且不同于共享 Debug 证书
- [ ] 使用 `scripts/verify-release-signatures.ps1` 独立验证每个 APK/AAB
- [ ] 听读工坊 EXE/MSI 的 Authenticode 状态为 `Valid`
- [ ] 使用 `scripts/verify-authenticode.ps1` 核对 Windows 签名证书 SHA-256
- [ ] 正式产物、校验和、证书身份和时间戳结果已写入批次证据

## 四、首次运行、权限与隐私

- [ ] 干净用户可理解产品用途、联网边界、数据位置、权限用途和清除入口
- [ ] 每项敏感权限按功能触发；拒绝、取消、撤销后有明确且可恢复的降级路径
- [ ] 日志、崩溃信息、导出和备份不含令牌、支付页面、私人笔记或音频正文
- [ ] 联网发送文本或音频前明确接收方、用途和限制
- [ ] 截图保护、敏感界面返回路径、圆屏安全区和字体缩放符合产品要求

## 五、升级、数据与恢复

- [ ] 从每个支持的旧版本执行保数据覆盖升级，不以卸载重装规避问题
- [ ] 迁移成功、失败安全重试、回滚或恢复路径均有证据
- [ ] 导出格式、范围和敏感性提示正确；重复导入或恢复符合产品规则
- [ ] 业务数据、缓存、凭据和全部本机数据的清除范围清晰，破坏性操作二次确认
- [ ] 清除不误删外部文件、另一设备数据、云端原文、系统权限或配对信息

## 六、产品专项验收

### X3VoiceLedger

- [ ] Watch/Phone 覆盖升级、BLE 同步、冲突顺序和断连恢复通过
- [ ] JSON 导出、恢复、重复恢复、分类清除和外部文件保留通过
- [ ] 支付自动记账默认关闭、单独授权、限制明确；关闭后停止采集
- [ ] API 30 与目标较新系统上验证受保护系统广播兼容行为

### X3WolaiNotes

- [ ] 个人 GitHub 预览版默认无 Token，并明确提示个人 Token 不是 OAuth
- [ ] 用户仅在临时导入窗口输入 Token；Token 仅本机加密保存，不进入 APK、日志、导出或备份，且只能删除后重导
- [ ] 已配置 Token、同步页 ID、收藏页 ID 均只显示用途、状态和可信时间，无常驻输入框、明文回填或直接修改入口
- [ ] 满足 `X3WolaiNotes/docs/OAUTH_RELEASE_READINESS.md` 全部放行条件
- [ ] 正式 OAuth 的授权、取消、刷新、失效、撤销和重新授权通过
- [ ] 页面配置、速记、收藏、子页面、导出导入与分类清除通过
- [ ] Release 不包含或接受 Debug 旧令牌、App Secret、编译时私人页面 ID

### X3OfflineReader Watch

- [ ] 覆盖升级、书库/音乐导入、播放、断点、收藏、倍速和 LRC 通过
- [ ] 备份恢复、分类清除、源文件保留、权限拒绝与取消通过
- [ ] OPPO Watch X3 圆屏、表冠/手势、音频输出和长时播放通过

### 听读工坊

- [ ] 未签名预览仅以含 UNSIGNED-PREVIEW 标识的便携 ZIP 发布，附未知发布者提示、源提交和 SHA-256，且不含安装器
- [ ] 正式安装包升级、开始菜单、GUI/CLI、工作目录迁移和卸载通过
- [ ] 中断续作、缓存复用、失败保留旧目录、输出重试和回滚通过
- [ ] 在线音色逐任务授权、正文外发说明、清理范围和私人工作目录隔离通过

## 七、证据与放行

- [ ] 真机/目标 Windows 证据保存在项目文档根，未写入私人内容或秘密
- [ ] README、隐私说明、版本记录、已知限制、逐产品 Wolai 页面和总索引已同步
- [ ] 产品负责人复核所有不适用项均有理由，所有失败项均已关闭
- [ ] 代码审计结论与生产发布结论分别记录
- [ ] 最终生产发布结论为 `PASS / READY`

个人预览版只能给出 LIMITED PREVIEW。若缺正式 OAuth、Release Key、Authenticode 证书、签名成品或目标环境验收，正式生产最后一项不得勾选。
