# X3WolaiNotes 数据生命周期

## 数据分类

| 数据 | 保存位置 | 导出 | 清除 |
|---|---|---|---|
| 本地速记、待办和同步状态 | 应用私有 SQLite | JSON，未加密 | 可单独清除 |
| 最近访问页面的 ID、标题和时间 | 应用私有 SQLite，最多 10 条 | JSON，未加密 | 可单独清除 |
| Wolai 在线页面正文、表格、媒体 | 仅当前界面内存 | 不导出 | 退出阅读页即释放 |
| Wolai 授权令牌 | Android Keystore 加密后的应用私有配置；界面只显示导入时间和状态 | 永不导出 | 只能删除后重新导入 |
| 同步页、收藏页 ID | 应用私有配置；界面只显示用途、配置状态和时间 | 不导出 | 只能删除后重新配置，或随全部数据清除 |
| 系统权限和系统网络设置 | Android 系统 | 不导出 | 应用内清除不修改 |

## 备份与恢复

- 导出采用 UTF-8 JSON，schema 为 `1`，最大 8 MiB、最多 50,000 条本地记录。
- 文件含本地笔记正文且未加密，界面在导出前明确提示用户妥善保管。
- 导入先完整读取并校验产品类型、schema、大小、数量、字段长度、枚举值和重复 ID，再开启数据库事务。
- 恢复采用无损合并：新 ID 写入；同 ID 保留设备现有记录，旧备份不会覆盖当前同步状态；重复导入安全。
- 最近访问按页面 ID 合并，仍由数据库限制为最多 10 条。
- 授权令牌、页面配置和在线内容不进入备份；换机后必须重新配置页面并重新授权。

## 清除与撤销

- “清除本地笔记”不删除 Wolai 中已经创建的块。
- “清除最近访问”只删除本机元数据。
- “清除本机授权”删除密文、临时授权文件和不可导出的 Keystore 密钥。
- “清除全部本机数据”删除上述本地业务数据、最近访问、页面配置和本机授权，但不修改系统权限。
- 所有破坏性操作都需要在用户选择具体操作后再次确认。
- 目前没有从 Wolai 官方资料核实到 OAuth 撤销端点；因此本机清除不等于远端撤销，用户还需在 Wolai 账户侧撤销应用访问。

## 个人预览授权与正式发布门槛

个人 GitHub 预览版允许用户在“数据与授权”的临时导入窗口输入自己持有的个人 Token。默认不配置，导入前明确说明它不是 OAuth；Token 经 Android Keystore 加密后留在应用私有存储，不回显、不进 APK、日志、导出或备份。导入后只显示状态与导入时间，不提供常驻输入框或修改入口；更换必须先删除后重新导入。同步页与收藏页 ID 同样只在临时配置窗口输入，保存后只显示用途、状态与时间。ADB 文件导入仍只限 Debug，Release BuildConfig 不含私人页面 ID 或 Token。

正式公共生产版仍需以下外部输入：

1. Wolai 官方确认的 OAuth 授权端点、令牌端点、撤销端点、作用域和回调规则；
2. 已注册的公开客户端，或经批准的可信中转服务（如客户端密钥不能安全放入 APK）；
3. 授权、刷新、失效、撤销和重新授权的测试账号证据。

在这些条件满足前，产品只能按 LIMITED PREVIEW 发布，不得宣称已完成正式 OAuth 或正式公共生产验收。
