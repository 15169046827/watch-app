# EPUB 逻辑章节与标题

EPUB 的 spine 表示阅读顺序，单个 XHTML 文件可能包含多章，也可能只是某章的一段。转换器不能把 HTML 文件数量直接当作小说章节数量。

## 识别规则

- 按 spine 顺序收集可读正文块，包含 h1–h6、段落、列表项和引用。
- 独立、短小的中文编号标题（如“第12章 标题”）或英文编号标题（如“Chapter 12”）建立章节边界。含正文句末标点的叙述、直接接在章节号后的叙述和引用块不会触发切章。
- 存在编号边界时，某个文件开头、首个边界之前的正文归入上一逻辑章；书籍开头的这类内容保留为前言。
- 拆分文件开头的语义标题若与上一章具有相同的阿拉伯数字编号，只保留一次标题，将续文连接到上一章。
- 没有编号边界的文档如果有独立的导航名或语义标题，仍保留独立目录项；全书完全没有编号边界时继续以 spine 文档作为兼容回退。
- 章节名使用正文 h1/h2、NCX/EPUB 3 导航名或有效 HTML 标题。哈希和无空格的字母数字内部代码不能作为回退标题，最终回退为前言或顺序章节名。
- 编号段落提升为章节标题时仅朗读一次；普通段落的文本和顺序保持不变。

导航信息用于文档标题回退；同一 XHTML 中只有无编号导航锚点、且正文没有可识别标题的细分结构，目前仍按文档回退。当前实现不声称支持所有排版样式。

XML 大小上限、禁用外部 DTD/实体、拒绝内部实体子集、路径安全和 DRM 拒绝规则继续执行。

## 已生成文件与缓存

修复影响后续转换。旧 .opbook 已经包含合并后的目录和错误标题的实际音频，更新转换器不会改变这些成品，需从 EPUB 重新转换。建议使用新的输出文件名，核对后再替换旧文件。

重新转换可以复用文本、音色和语速匹配的有效句子缓存；每个 Track 的签名包含实际句子文件序列和时长，章节内容变化时旧 Track 不会通过签名校验。无需清空全局缓存或删除私人断点。

手表索引保留旧文件的目录信息。试听确认新成品后，先仅移除旧书库索引，再选择新文件导入；不要在尚未确认新文件可用时删除旧源文件。

## 本机修复与清理

本机便携预览可在程序关闭后原子替换已验证的 Java 转换核心，保留原 GUI、CLI、工作目录和开始菜单入口。使用隔离任务目录验证原 CLI 的实际转换和原 GUI 的启动退出后，移除回滚暂存、公开测试产物及临时快捷方式。

本机修改后的解压目录须注明本地修复及核心 SHA-256；它不代表重新发布的预览 ZIP。正式签名与预览发布仍遵循现有打包门禁。
