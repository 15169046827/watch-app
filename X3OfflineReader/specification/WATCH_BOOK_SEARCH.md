# Watch 0.6.0 书内搜索

## 范围

书内搜索只面向已加入小说书库的本地 `.opbook`。它读取包内既有 `content/*.json` 正文索引和 `timeline/*.json` 时间轴，不改变开放格式、Builder 输出、SQLite 数据、音乐库或播放服务，也不扫描音频内容。

## 搜索契约

- 搜索词会去除首尾空白并限制为 64 个 Unicode 码点；空搜索词不会启动读取。
- 中文和其他 Unicode 字符按原文精确匹配，ASCII 字母不区分大小写。
- 每章在后台依次读取正文与时间轴，单个 JSON 继续遵守 16 MiB 安全上限；最多返回 100 条结果，避免圆屏列表和内存无限增长。
- 同一时间轴句段内的多个命中合并为一条。摘要仅保留命中附近的有限正文，不写入数据库、日志、外部文档或包文件。
- 搜索只访问用户已经授权且通过索引验证的源文件；源 `.opbook` 缺失或授权失效时沿用书库现有提示。

## 界面与导航

- 章节页在“续听”和“书签”旁提供“搜索”入口；搜索页包含单行输入、搜索按钮、状态文字和结果列表。
- 搜索运行期间暂时锁定输入与按钮，完成后显示结果数量；无结果、达到 100 条上限或读取失败都有明确状态。
- 每条结果显示逻辑章节标题、章内累计时间和正文摘要，不暴露 Track ID 或 Track 分片。
- 命中正文通过 Timeline 映射到覆盖该字符范围的句段起点；点击结果把完整书籍队列定位到对应 Track 和精确毫秒位置。

## 验证

- JVM 单元覆盖 ASCII 大小写匹配、Unicode 摘要边界、结果文案与逻辑章节时间格式。
- 自包含仪器用例创建公开测试书、正文和时间轴，验证章节入口、真实 JSON 搜索、逻辑章节累计时间、圆屏结果边界和播放器精确导航参数；用例结束清理测试记录与文件。
- 发布前执行 Watch 单元测试、Debug/AndroidTest APK 编译、Android Lint、共享 Debug 签名校验，再在已确认连接的 OPPO Watch X3 上验证输入、结果、跳转、返回和源文件异常行为。
