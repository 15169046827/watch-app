# 听读 / 听读工坊数据生命周期

本文记录 WARS 1.0 公共安装版的数据边界、迁移、导出和清理约定。源文件和用户输出始终由用户控制。

## 手表端“听读”0.8.0

手表端完全离线，不申请网络权限。用户选择的 `.opbook`、音乐和 LRC 是外部源文件；App 只持有文件授权、目录索引、按需播放缓存、进度、收藏与播放设置。

“数据与迁移”可导出未加密 JSON，产品标识为 `X3OfflineReaderWatch`，Schema 为 `1`，最大 4 MiB、每类最多 10,000 项。内容仅包括小说章节进度、小说收藏、小说倍速、音乐进度、音乐收藏、音乐倍速和音乐播放模式。备份明确不包含 `.opbook`、音频、歌词、正文、封面、索引缓存或播放缓存；音乐路径和书籍标识属于敏感元数据，用户应自行安全保管导出文件。

恢复前必须先重新导入同一本书并重新扫描音乐。只有本机已存在的书、章节、Track 或音乐路径会匹配恢复；未知项跳过。现有较新的进度优先，收藏和设置按稳定键幂等写入，因此中断后可重试，不需要先清空现有数据。

2026-09-14 在 OPPO Watch X3 上以随机命名的隔离数据库完成合成迁移测试：验证小说和音乐进度、收藏的恢复，未匹配内容跳过、较新本地进度保持及未来格式拒绝（1/1 通过）；未导出或恢复真实书库、音乐路径和进度。测试数据库和临时测试组件已清理。

清理均需二次确认：

- “清除播放数据”删除进度、收藏和播放设置，并恢复默认倍速与播放模式。
- “清除小说索引与缓存”停止播放、释放文件授权并删除 App 私有索引和按需缓存，但不删除外部 `.opbook`。
- “清除音乐目录”删除 App 内音乐目录、隐藏记录、进度和设置，但不删除外部音乐或 LRC。
- “清除全部本机数据”执行以上操作并重置首次数据说明。

书库原有的“连同源文件删除”是独立、明确标示的文件管理操作，不属于上述 App 级清理。

## Windows“听读工坊”0.7.0

源 EPUB/TXT、封面和输出 `.opbook` 不复制到界面设置。持久工作目录默认位于 `%LOCALAPPDATA%\Canace\X3AudiobookBuilder\work`，也可用绝对路径 `X3_BUILDER_WORK_ROOT` 指定；其中保存句子缓存、断点、未完成 Track 与短期控制文件。

界面设置保存在当前 Windows 用户的 WebView 本地存储，可能包含最近选择目录、TTS/音色/语速和导出偏好。来源识别历史最多保存 50 项来源路径组合、书名和作者，不保存正文。用户可在“存储管理”中清除界面设置与识别历史，不影响任务、断点、缓存、源文件或输出文件。

缓存、断点和未完成 Track 与本机绝对路径、运行环境及大型模型绑定，因此不提供可移植导出；迁移由 0.6.4 起的逐文件 SHA-256 校验迁移承担。用户可整理超出 20 GiB 或 180 天的句子缓存、单独清空句子缓存，或经确认删除超过 30 天的未完成任务。所有操作明确说明是否影响断点；任何一种都不删除源文件或已输出 `.opbook`。

离线 Provider 不发送正文。只有用户选择 Microsoft Edge 在线音色并对每个新任务单独确认后，待朗读正文才发送给在线服务；选择状态本身不构成下一任务授权。

## 预览分发与公共安装版签名

手表 Release 构建只接受工作区共享 Android Release 证书配置，缺失时失败；Debug 仍固定使用工作区共享 Debug Key。Windows 正式打包必须在开始构建和替换程序前提供预期证书 SHA-256、HTTPS 时间戳地址和 `signtool.exe`，并在当前用户证书库找到相同 SHA-256 且含私钥的证书。最终 `X3AudiobookBuilder.exe` 与 `X3BuilderCLI.exe` 均签名，再由独立脚本确认 Authenticode 状态为 `Valid` 且签名者 SHA-256 完全一致。缺少任何条件时不生成或覆盖正式包。

WARS 1.1 允许个人 GitHub 未签名便携预览：仅从已审核的干净 X3OfflineReader 工作树生成，GUI/CLI 必须均为 `NotSigned`，文件名和随包说明含 `UNSIGNED-PREVIEW`，并公布源提交及 ZIP SHA-256。该路径不生成 MSI/EXE 安装器、不创建开始菜单、不迁移私人工作目录、不覆盖正式包，发布结论只能是 `LIMITED_PREVIEW`。正式生产的 Authenticode 门禁保持不变。
